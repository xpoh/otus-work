# Домашнее задание
## Словари

## Цель:
закрепить навыки работы со словарями и оконными функциями для выборки данных и вычисления
аккумулятивной суммы;


## Описание/Пошаговая инструкция выполнения домашнего задания:
- Создайте таблицу с полями:
    - user_id UInt64,
    - action String,
    - expense UInt64.

Создайте словарь, где ключ — user_id, атрибут — email (String), источник словаря выберите любой 
удобный, например, файл.
Наполните таблицу и источник данными с низкоардинальными значениями для поля action и несколькими
повторяющимися строками для каждого user_id.

Напишите SELECT, который возвращает:
email с помощью dictGet,
аккумулятивную сумму expense с окном по action,
сортировку по email.
